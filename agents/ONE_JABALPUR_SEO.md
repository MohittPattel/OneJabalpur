# 9. PAGE CREATION RULE

Before creating ANY page, answer:

1. What is the user searching for?
2. What is the primary keyword?
3. What is the search intent?
4. Does this page deserve to exist?
5. Is there already another One Jabalpur page targeting the same intent?
6. What unique information will this page provide?
7. Which existing pages should link to it?
8. Which pages should this page link to?

If there is already a page satisfying the same search intent,
DO NOT create another competing page.

# 22. DUPLICATE CONTENT RULE

Avoid multiple pages targeting the same keyword/search intent.

For example, do NOT create:

/best-cafes-jabalpur/

/best-cafes-in-jabalpur/

/top-cafes-jabalpur/

/top-10-cafes-in-jabalpur/

if all four contain essentially the same content.

Prefer ONE authoritative page:

/best-cafes-in-jabalpur/

Then expand it over time.

# 27. GOOGLE SEARCH CONSOLE

Google Search Console should be treated as the primary SEO monitoring tool.

Set up:

1. Verify domain ownership
2. Submit sitemap.xml
3. Check indexing
4. Monitor search queries
5. Monitor impressions
6. Monitor clicks
7. Monitor CTR
8. Monitor average position
9. Inspect important URLs
10. Monitor indexing problems

Do not assume that submitting a sitemap guarantees indexing.

---

# 28. SITEMAP

Create:

/sitemap.xml

The sitemap should contain canonical, indexable URLs.

Do NOT include:

- Deleted pages
- Redirected URLs
- Noindex pages
- Duplicate URLs
- Temporary URLs

Update the sitemap when new pages are added.

For a Next.js implementation, use the framework's sitemap
functionality where appropriate.

---

# 29. ROBOTS.TXT

Create:

/robots.txt

The site should allow search engines to crawl important public pages.

Reference the sitemap.

Example concept:

User-agent: *
Allow: /

Sitemap:
https://onejabalpur.com/sitemap.xml

Do not accidentally block:

- CSS
- JavaScript
- Important images
- Public pages

---

# 30. INDEXING STRATEGY

Do not expect Google to index the entire website immediately.

Prioritize:

1. Homepage
2. Main category pages
3. Major destination/place pages
4. Major food/cafe pages
5. Event hub
6. Important business pages
7. Supporting content

After publishing:

- Submit sitemap
- Request indexing for important new pages
- Build internal links
- Monitor Search Console

Do not repeatedly request indexing for every minor change.

# 35. CORE WEB VITALS

Performance is important.

Prioritize:

- Fast Largest Contentful Paint
- Low Cumulative Layout Shift
- Good Interaction to Next Paint
- Optimized images
- Minimal unnecessary JavaScript
- Lazy loading where appropriate
- Efficient fonts
- Responsive design

Avoid loading huge images simply because they look good on desktop.
